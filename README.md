# java-calculator-precourse
### 요구사항 정의
- 구분자와 양수로 구분된 문자열을 입력받는다.
    - 구분자는 기본 구분자와 커스텀 구분자로 나뉜다.
    - 기본 구분자는 쉼표(,)와 세미콜론(;)이다.
    - 커스텀 구분자는 문자열 맨 앞에 "//"와 "\n" 사이에 위치한다.
    - 예: //3\n => 3
- 문자열에서 구분자로 구분된 양수를 추출해야 한다.
- 양수의 합을 구해야 한다.
- 사용자가 잘못된 값을 입력한 경우 `IllegalArgumentException`을 발생시킨 후 종료해야 한다.
---
### 기능사항 정의
- [x] 사용자로부터 문자열을 입력받는다.
- [x] 문자열에는 기본 구분자와 커스텀 구분자, 양수로 구성되어야 한다.
    - [x] 이외의 입력이 들어있으면 `IllegalArgumentException`을 발생시킨다.
- [x] 문자열로부터 양수를 추출한다.
- [x] 추출된 양수의 합을 반환한다.
- [x] 양수 합 결과를 화면에 출력한다.
---
### 리팩토링 대상 확인
- [x] 매직 넘버와 매직 문자열을 제거한다.
- [x] Application 클래스의 `main`이 가지는 책임을 분리한다.
- [ ] 문자열에 실수가 있을 때 실수 합이 가능하도록 수정한다.
  - "1.2:3" -> 4.2
  - "//.\n1.2.3:4,5" -> 15
